# روائع الماضي — موقع عربي لبيع وشراء العملات والطوابع

موقع إلكتروني كامل باللغة العربية (RTL)، بهوية بصرية تعتمد **البيج الفاتح** مع لمسة **خزامي/بنفسجي**، ومناسب لجميع الأعمار.

🔗 المستودع على GitHub: https://github.com/adhambaksh-create/rawai3-al-madi

## طريقة التشغيل

افتح الملف `index.html` بالنقر المزدوج في أي متصفح حديث. لا يحتاج تثبيتاً أو خادماً.

> ملاحظة: الخطوط تُحمّل من Google Fonts، لذا يفضّل وجود اتصال بالإنترنت. يوجد بديل محلي احتياطي للخطوط إذا لم يتوفر الاتصال.

## العمل مع VS Code

المشروع مهيّأ للعمل في VS Code:

1. افتح المجلد: `File > Open Folder` واختر مجلد المشروع.
2. سيقترح VS Code تثبيت الإضافات الموجودة في `.vscode/extensions.json` (أهمها **Live Server**).
3. لتشغيل الموقع: انقر على `index.html` بالزر الأيمن واختر **Open with Live Server**، أو من قائمة `Terminal > Run Task...` اختر **تشغيل الخادم المحلي** ثم افتح `http://localhost:5500/`.
4. للتشغيل مع التنقيح: اضغط `F5` واختر **تشغيل الموقع في Chrome**.

ملفات الإعداد داخل `.vscode/` جاهزة، و`serve.ps1` خادم محلي بسيط يعمل على Windows دون Python أو Node.js.

## تخزين البيانات

النسخة الحالية **تجريبية** وتحفظ البيانات في متصفحك عبر `localStorage`، مع جسر احتياطي عبر `window.name` لضمان مشاركة السلة والحساب بين الصفحات عند فتح الملفات مباشرة من القرص.

لإعادة البيانات لأصلها: افتح أي صفحة، ثم من أدوات المطوّر (F12) نفّذ:

```js
localStorage.clear();
window.name = '';
location.reload();
```

لتحويل الموقع إلى إنتاج حقيقي، استبدل طبقة `assets/js/store.js` بخادم وقاعدة بيانات (مثل PHP/MySQL أو Node.js) مع نظام مصادقة آمن وتخزين صور حقيقي.
